# subcontractor.gr

B2B πλατφόρμα υπεργολαβιών για όλες τις ειδικότητες της οικοδομής. Ο **εργολάβος** δημοσιεύει εργασία με προμέτρηση (BOQ) και σχέδια. Οι **υπεργολάβοι** τιμολογούν γραμμή-γραμμή. Ο εργολάβος συγκρίνει, ζητά βελτιωμένη προσφορά και αναθέτει, όλη την εργασία ή ανά ενότητα. Μετά την ανάθεση, τα μέρη συνεργάζονται στην πλατφόρμα (μηνύματα, συμφωνητικό, αξιολογήσεις).

- Backend: Django 4.2–6 + Django REST Framework (token auth)
- Frontend: JavaScript (ES modules, χωρίς build step), σερβίρεται από το Django
- Βάση: SQLite τοπικά, PostgreSQL σε server

## Online (Render)

Το `render.yaml` στήνει web service και PostgreSQL. Κάθε push στο `main` κάνει αυτόματα νέο deploy.

- **Πρώτη φορά:** Render → **New → Blueprint** → επιλογή του repo → **Apply**.
- **Domain:** Settings → Custom Domains → `subcontractor.gr` και `www.subcontractor.gr`, με τις εγγραφές DNS που δείχνει το Render στον καταχωρητή.
- **Ρυθμίσεις:** στο service → **Environment** (δείτε τον πίνακα παρακάτω).

### Ρυθμίσεις (μεταβλητές περιβάλλοντος)

| Μεταβλητή | Τι κάνει |
|---|---|
| `DJANGO_SECRET_KEY` | Δημιουργείται αυτόματα από το Render |
| `DATABASE_URL` | Σύνδεση PostgreSQL, αυτόματα από το Render |
| `SITE_URL` | Διεύθυνση για τους συνδέσμους στα email (`https://subcontractor.gr`) |
| `EMAIL_HOST`, `EMAIL_PORT` (587), `EMAIL_HOST_USER`, `EMAIL_HOST_PASSWORD` | SMTP για τα email. Παραδείγματα: Brevo `smtp-relay.brevo.com`, Microsoft 365 `smtp.office365.com`. **Χωρίς αυτά δεν στέλνονται email** (οι ειδοποιήσεις φαίνονται μόνο στο καμπανάκι) |
| `DEFAULT_FROM_EMAIL` | Αποστολέας, π.χ. `subcontractor.gr <no-reply@subcontractor.gr>`. Το domain πρέπει να είναι επαληθευμένο στον πάροχο email (SPF/DKIM) |
| `REQUIRE_EMAIL_VERIFICATION` | `1`/`0`. Προεπιλογή: ενεργό όταν υπάρχει `EMAIL_HOST`. Χωρίς επιβεβαιωμένο email δεν γίνεται δημοσίευση εργασίας ή υποβολή προσφοράς |
| `AWS_STORAGE_BUCKET_NAME`, `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_S3_ENDPOINT_URL` | Μόνιμη αποθήκευση αρχείων (σχέδια, φωτογραφίες, συνημμένα) σε Cloudflare R2 ή Amazon S3. Για R2: endpoint `https://<account-id>.r2.cloudflarestorage.com`. **Χωρίς αυτά τα αρχεία χάνονται σε κάθε deploy** στο δωρεάν πλάνο |
| `MEDIA_ROOT` | Εναλλακτικά: φάκελος σε persistent disk (π.χ. `/var/data/media` με Render Disk) |
| `SEED_RESET` | `1` για ένα deploy: ξαναδημιουργεί τα demo δεδομένα (μόνο λογαριασμοί `@demo.gr`). Μετά επαναφέρετε σε `0` |

Οι αυτόματες ειδοποιήσεις (υπενθύμιση 24 ωρών, άνοιγμα προσφορών, λήξη BAFO) τρέχουν μόνες τους κάθε 10 λεπτά, όσο υπάρχει κίνηση στην εφαρμογή. Δεν χρειάζεται cron. Για ακρίβεια και χωρίς κίνηση, προσθέστε cron job: `python manage.py run_scheduled`.

## Τοπικά

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt          # σε Python 3.9: pip install "Django>=4.2,<4.3" djangorestframework openpyxl
python manage.py migrate
python manage.py seed_demo
python manage.py runserver               # http://127.0.0.1:8000
```

Τοπικά τα email δεν στέλνονται. Εμφανίζονται στο terminal του `runserver`, μαζί με τους συνδέσμους επιβεβαίωσης και επαναφοράς κωδικού. Admin: `python manage.py createsuperuser` → `/admin`. Tests: `python manage.py test`.

Υπάρχει και ρύθμιση για **GitHub Codespaces**: Code → Codespaces → Create codespace.

## Λειτουργίες

**Εργασίες και προσφορές**
- 37 ειδικότητες σε 4 ομάδες (`accounts/models.py`, `TRADE_GROUPS`). Κάθε εργασία δηλώνει ειδικότητες.
- Δημόσιες εργασίες, ή ιδιωτικές μόνο για προσκεκλημένους. Προσκλήσεις από την εργασία ή από το προφίλ υπεργολάβου.
- Εισαγωγή BOQ από Excel/CSV με αυτόματο εντοπισμό στηλών, ενότητες, χειροκίνητος επεξεργαστής.
- Σχέδια και έγγραφα με εκδόσεις. Μετά τη δημοσίευση ανεβαίνουν ως συμπληρώματα, και οι παλαιότερες προσφορές σημαίνονται.
- Ανώνυμες ερωτήσεις με δημόσιες απαντήσεις.
- Σφραγισμένες προσφορές μέχρι τη λήξη. Μερική προσφορά: ο υπεργολάβος εξαιρεί ενότητες.
- Σύγκριση γραμμή-προς-γραμμή:
  - σύνολα ανά ενότητα και βέλτιστος συνδυασμός
  - σήμανση χαμηλότερης τιμής, αποκλίσεων και γραμμών χωρίς τιμή
  - στήλη «Αγορά»
  - εξαγωγή σε Excel
- **BAFO:** γύρος βελτιωμένης προσφοράς για επιλεγμένους υπεργολάβους, με σφραγισμένες αναθεωρήσεις μέχρι τη λήξη.
- Ανάθεση όλης της εργασίας ή ανά ενότητα σε διαφορετικούς υπεργολάβους.

**Μετά την ανάθεση**
- Συνομιλία εργολάβου με κάθε ανάδοχο, με συνημμένα.
- Ιδιωτικό συμφωνητικό υπεργολαβίας για εκτύπωση/PDF, με παράρτημα τιμών, για ψηφιακή θεώρηση στην ΑΑΔΕ (άρθρο 19 Ν. 820/1978).
- Αξιολογήσεις και από τις δύο πλευρές με κριτήρια. Εμφανίζονται στο προφίλ και στον κατάλογο.

**Προφίλ, κατάλογος, τιμές**
- Δημόσιο προφίλ εταιρείας με έργα (και φωτογραφίες), στατιστικά πλατφόρμας και αξιολογήσεις.
- Κατάλογος εργολάβων και υπεργολάβων με φίλτρα. Η αναζήτηση αγνοεί κεφαλαία και τόνους.
- **Τιμοκατάλογος:** στη φόρμα προσφοράς προτείνονται οι τιμές που έδωσε ο ίδιος ο υπεργολάβος σε παρόμοιες γραμμές.
- **Δείκτες τιμών:** ανώνυμος διάμεσος και εύρος ανά είδος, μονάδα και περιφέρεια. Υπολογίζονται μόνο από κλειστές δημόσιες εργασίες, με τουλάχιστον 3 εταιρείες και μία τιμή ανά εταιρεία.

**Λογαριασμοί και ειδοποιήσεις**
- Επιβεβαίωση email, επαναφορά κωδικού, αποδοχή όρων στην εγγραφή.
- Ειδοποιήσεις στο καμπανάκι και με email, με επιλογή ανά είδος:
  - νέα εργασία στην ειδικότητα και περιοχή
  - πρόσκληση
  - συμπλήρωμα
  - ερώτηση ή απάντηση
  - υπενθύμιση προθεσμίας
  - άνοιγμα προσφορών
  - BAFO
  - ανάθεση
  - μήνυμα
  - αξιολόγηση
- Όροι χρήσης και πολιτική απορρήτου: **προσχέδια** στο `frontend/static/js/views/legal.js`. Συμπληρώστε τα στοιχεία της εταιρείας και δώστε τα για νομικό έλεγχο.

```
  views.py          REST API εργασιών, προσφορών, προσκλήσεων, BAFO, ανάθεσης
  collab.py         μηνύματα, αξιολογήσεις, συμφωνητικό
  comparison.py     σύγκριση προσφορών και εξαγωγή Excel
  pricing.py        τιμοκατάλογος και δείκτες τιμών

  events.py         ειδοποιήσεις από γεγονότα εργασιών
notify/             ειδοποιήσεις (in-app και email), προγραμματισμένες υπενθυμίσεις
frontend/           index.html, static/js (app.js, views/*.js), static/css
```
