# ElectroBid: B2B πλατφόρμα προσφορών ηλεκτρολογικών έργων

Ο **εργολάβος** δημοσιεύει εργασία με προμέτρηση (BOQ) και σχέδια. Οι **υπεργολάβοι** τιμολογούν την προμέτρηση γραμμή-γραμμή. Ο εργολάβος συγκρίνει τις προσφορές σε κοινό πίνακα και κάνει ανάθεση.

- Backend: Django (4.2 έως 6) + Django REST Framework (token auth)
- Frontend: JavaScript (ES modules, χωρίς build step), σερβίρεται από το Django
- Βάση: SQLite για ανάπτυξη (για παραγωγή PostgreSQL)

## Online στο Render (ενημερώνεται αυτόματα από το GitHub)

1. Στο https://render.com συνδεθείτε με τον λογαριασμό GitHub.
2. **New → Blueprint**, επιλέξτε αυτό το repo και πατήστε **Apply**. Το `render.yaml` δημιουργεί web service και βάση PostgreSQL και φορτώνει τα demo δεδομένα.
3. Η εφαρμογή ανοίγει στο `https://electrobid-xxxx.onrender.com`. Κάθε push στο `main` κάνει νέο deploy.

Στο δωρεάν πλάνο ο server «κοιμάται» μετά από αδράνεια και τα ανεβασμένα αρχεία (σχέδια, φωτογραφίες) χάνονται σε κάθε deploy ή restart. Για πραγματική χρήση χρειάζεται πληρωμένο πλάνο με persistent disk ή αποθήκευση αρχείων σε S3/R2.

## Εκκίνηση από το GitHub (Codespaces, χωρίς εγκατάσταση)

Στη σελίδα του repo: **Code → Codespaces → Create codespace on main**. Σε 2-3 λεπτά εγκαθίστανται όλα, φορτώνονται τα demo δεδομένα και ανοίγει η εφαρμογή σε νέα καρτέλα. Αν δεν ανοίξει, πηγαίνετε στην καρτέλα **Ports** και ανοίξτε τη θύρα 8000.

## Εκκίνηση τοπικά

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
```

## Τι κάνει

**Εργολάβος**
- Δημιουργεί εργασία: περιγραφή, περιφέρεια, κατηγορία, ελάχιστη άδεια υπεργολάβου, προθεσμία, έναρξη.
- Εισάγει προμέτρηση από Excel/CSV. Οι στήλες «Α/Α», «Περιγραφή», «Μονάδα», «Ποσότητα» εντοπίζονται αυτόματα. Γραμμές χωρίς ποσότητα γίνονται ενότητες και οι γραμμές «Σύνολο»/«ΦΠΑ» αγνοούνται. Υπάρχει και χειροκίνητος επεξεργαστής.
- Ανεβάζει σχέδια και έγγραφα (PDF, DWG/DXF, Excel, Word, εικόνες, ZIP). Αρχείο με τον ίδιο τίτλο αποθηκεύεται ως νέα έκδοση.
- Δημοσιεύει. Από εκεί και πέρα η προμέτρηση κλειδώνει. Νέα αρχεία ανεβαίνουν ως **συμπληρώματα** και οι προσφορές που δόθηκαν πριν σημαίνονται ως «παλαιότερης έκδοσης».
- Απαντά σε ερωτήσεις. Οι απαντήσεις δημοσιεύονται σε όλους, ανώνυμα ως προς το ποιος ρώτησε.
- Μπορεί να δώσει παράταση, να λήξει νωρίτερα την υποβολή ή να ακυρώσει την εργασία.
- **Σφραγισμένες προσφορές**: πριν τη λήξη βλέπει μόνο πόσες έχουν υποβληθεί.
- Μετά τη λήξη βλέπει **σύγκριση γραμμή-προς-γραμμή**:
  - κατάταξη προσφορών και απόκλιση από τη χαμηλότερη (%)
  - η χαμηλότερη τιμή κάθε γραμμής σημαίνεται με πράσινο
  - τιμές ±30% από τη διάμεσο σημαίνονται με πορτοκαλί
  - γραμμές χωρίς τιμή σημαίνονται με κόκκινο
  - εξαγωγή της σύγκρισης σε Excel
- Κάνει ανάθεση.

**Προφίλ και κατάλογος (και οι δύο πλευρές)**
- Δημόσιο προφίλ εταιρείας: παρουσίαση, έτος ίδρυσης και έτη εμπειρίας, προσωπικό, άδεια, ειδικότητες, περιοχές δραστηριότητας, τηλέφωνο, ιστοσελίδα.
- Έργα και εμπειρία: τίτλος, πελάτης, τοποθεσία, έτος, κατηγορία, ύψος εργασιών, αντικείμενο, περιγραφή και φωτογραφία.
- Στατιστικά από την πλατφόρμα: εργασίες και αναθέσεις για εργολάβους, προσφορές και αναθέσεις που κέρδισαν για υπεργολάβους.
- Στο προφίλ εργολάβου εμφανίζονται και οι ανοιχτές εργασίες του.
- Κατάλογος: ο εργολάβος ψάχνει υπεργολάβους και ο υπεργολάβος εργολάβους. Φίλτρα για περιοχή (έδρα ή περιοχή δραστηριότητας), ειδικότητα, ελάχιστη άδεια και επαληθευμένες εταιρείες. Η αναζήτηση καλύπτει όνομα, πόλη, έργα και πελάτες και αγνοεί κεφαλαία και τόνους.
- Τα ονόματα εταιρειών σε εργασίες και προσφορές οδηγούν στο προφίλ τους.

**Υπεργολάβος**
- Βλέπει τις ανοιχτές εργασίες (marketplace) με φίλτρα περιφέρειας, κατηγορίας και αναζήτηση.
- Κατεβάζει σχέδια, βλέπει PDF στον browser και κατεβάζει την προμέτρηση σε CSV.
- Υποβάλλει ανώνυμες ερωτήσεις.
- Τιμολογεί κάθε γραμμή με σημείωση ανά γραμμή. Μπορεί να επικολλήσει μια στήλη τιμών από Excel. Δηλώνει χρόνο εκτέλεσης, ισχύ, όρους πληρωμής και εξαιρέσεις.
- Αποθηκεύει πρόχειρο, υποβάλλει, αλλάζει ή αποσύρει την προσφορά μέχρι τη λήξη.
- Δεν μπορεί να δώσει προσφορά αν η άδειά του είναι κατώτερη από την απαιτούμενη (Α < Β < Γ < Δ).
- Βλέπει το αποτέλεσμα στο «Οι προσφορές μου».

## Δομή

```
config/            ρυθμίσεις και URLs
accounts/          χρήστης (email login, ρόλος) και εταιρεία (ΑΦΜ, άδεια, ειδικότητες, περιοχές)
tenders/
  models.py        Job, JobDocument, BOQItem, JobQuestion, Bid, BidLine
  views.py         REST API και επιχειρησιακοί κανόνες
  boq_import.py    ανάγνωση προμέτρησης από Excel/CSV
  comparison.py    σύγκριση προσφορών και εξαγωγή Excel
  tests.py         tests για ροή, δικαιώματα, εισαγωγή, σφράγιση
  management/commands/seed_demo.py
frontend/
  index.html
  static/js/       app.js (router), api.js, ui.js, views/*.js
  static/css/app.css
```

## Βασικά endpoints (`/api/`)

| Μέθοδος | Διαδρομή | Περιγραφή |
|---|---|---|
| POST | auth/register, auth/login, auth/logout | λογαριασμός (επιστρέφει token) |
| GET/PATCH | me | προφίλ |
| GET | jobs | marketplace (`?region=&category=&q=`), `?scope=mine` για τις δικές μου |
| POST | jobs | νέα εργασία (εργολάβος) |
| GET/PATCH | jobs/{id} | λεπτομέρειες / αλλαγή (πρόχειρο, ή μόνο παράταση μετά τη δημοσίευση) |
| POST | jobs/{id}/publish, close_bidding, cancel, award | κύκλος ζωής |
| GET/PUT | jobs/{id}/boq | προμέτρηση |
| POST | jobs/{id}/boq/import | εισαγωγή από Excel/CSV |
| GET/POST | jobs/{id}/documents | έγγραφα / ανέβασμα (συμπλήρωμα μετά τη δημοσίευση) |
| GET | documents/{id}/download | λήψη με έλεγχο δικαιωμάτων |
| GET/POST | jobs/{id}/questions, questions/{qid}/answer | ερωτήσεις |
| GET/PUT | jobs/{id}/my-bid | η προσφορά μου |
| POST | jobs/{id}/my-bid/submit, my-bid/withdraw | υποβολή / απόσυρση |
| GET | jobs/{id}/comparison, comparison/export | σύγκριση (σφραγισμένη πριν τη λήξη) / Excel |
| GET | my-bids | οι προσφορές μου |
| GET | companies | κατάλογος (`?role=&region=&specialty=&license=&verified=1&q=`) |
| GET | companies/{id} | δημόσιο προφίλ με έργα, στατιστικά, ανοιχτές εργασίες |
| GET/POST | me/projects | τα έργα μου / νέο έργο (JSON ή multipart με φωτογραφία) |
| PATCH/DELETE | me/projects/{id} | αλλαγή / διαγραφή έργου |
| GET | projects/{id}/photo | φωτογραφία έργου |

Τα ανεβασμένα αρχεία δεν σερβίρονται δημόσια. Η λήψη περνά πάντα από το API.

## Για παραγωγή

- `DJANGO_SECRET_KEY`, `DJANGO_DEBUG=0`, `DJANGO_ALLOWED_HOSTS`
- PostgreSQL αντί για SQLite (αλλαγή στο `DATABASES`)
- Αποθήκευση αρχείων σε S3/Azure Blob (django-storages)
- `python manage.py collectstatic` και gunicorn/uvicorn πίσω από nginx
